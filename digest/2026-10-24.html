静态准确率与在线奖励价值，是两个目标

Scaling Laws for Generative Reward Models ↗
Angel Raychev · Nathan Lile · Rafael Rafailov
首发10月22日 01:37 EDT · v1；重叠窗口补收

延续 reward overoptimization（Gao 等，2022）的问题：在固定分布上判对故事偏好，不保证能指导变化中的 policy。原文在创意写作上比较 SFT Answer-Only 与 GRPO Thinking 两条 judge 训练管线。[1]

在线采样与 judge 的无效／冲突票过滤还会改变保留样本的分布。上式只是机制解释；原文未测出逐样本梯度贡献的分解。[1]

16 个配置拟合 6 个系数，peak Elo 的样本内 R²=0.954；没有跨尺度外推验证或独立训练 seed 区间。格式与训练目标同时改变，且 Gold 是学习模型，不能推出“思考会损害人类偏好质量”。[1]

低精度 RL：先核对“同一 policy”的三种含义

vLLM Delivers Day-0 Support for MiniMax-M3.1-Flash ↗
Inferact and the vLLM Team
技术博客首发／更新10月23日

只取博客中的训练方法部分：NVFP4 checkpoint 结合 veRL、FSDP2 与 LoRA，保持 base experts 冻结并同步 adapters。训练前核对权重传递、expert routing replay、同 token 的 logprob；权重相同仍可能有执行差异。[2]

为解释而写的 token-level IS 记号；原文说明 ratio cap=2
wt=ptrainer(at∣ht)prollout(at∣ht),wˉt=min⁡{2,wt}w_t=\frac{p_{\rm trainer}(a_t\mid h_t)}{p_{\rm rollout}(a_t\mid h_t)},\qquad \bar w_t=\min\{2,w_t\}wt​=prollout​(at​∣ht​)ptrainer​(at​∣ht​)​,wˉt​=min{2,wt​}

每个 batch 仅做一次 optimizer step，直接用 rollout logprobs 作 old logprobs，省去一次重算 forward。此条件不能直接移植到多 epoch 重用或更严重 stale 的训练。[2]

证据边界

这是一次可运行训练案例，不能证明 cap=2 对所有 GRPO 设置稳定，也不能据此把重复输出崩溃归因到单一原因。[2]

Muon、μP 与数据日程进入 320B MoE 配方

IQuest-Q1: Advancing Foundation Capabilities for Agentic CLI Systems ↗
A. Jian Yang et al.
10月22日 05:01 EDT · v1

320B 总参数／15B 激活；预训练结合 Stable SplitNorm、Muon、μP，后段增加 coding mixture。作者强调 safe 与 optimal learning rate 间保留裕量；这不是隔离 Muon 因果收益的实验。[3]

连续语义与离散生成的联合 scaling

Cola2: Co-Adaptive Hierarchical Language Modeling with Continuous Semantic Compression and Balanced Discrete Generation ↗
Hongcan Guo · Yian Zhao · Feng Wang · Shen Nie · Guoqiang Wei · Yan Zeng · Hengshuang Zhao
10月22日 10:04 EDT · v1

动态语义分段，token prediction 更新 encoder，flow prior 以 stop-gradient 解耦。约 210B tokens 的实验检查设计与 scaling；346.03B source tokens 的未收敛模型在八任务平均 60.10。跨模型的 token 差异不是严格 compute-matched 优势。[4]

数据来源：没有机器人轨迹，也能学控制先验

Learning Robot Behavior Priors from Non-Robotic Synthetic Data ↗
Mateusz Odrowaz-Sypniewski et al.
10月22日 09:43 EDT · v1

三类程序化控制抽象训练 Transformer，在未见机器人任务上出现非平凡零样本 action prediction。compute-matched 真实数据 baseline 只在其训练数据集上更强；这是数据来源与迁移比较，尚非普适的机器人 scaling law。[5]

固定 token 预算下的数据质量与可训练参数

AQL-Lite: Enabling Efficient Knowledge Acquisition for Arabic LLMs via Data-Centric Continual Pretraining ↗
Houssam Eddine Boukhalfa · Mourad Bouache · Mourad Dahmane
10月21日 15:04 EDT · v1

1B-token 匹配实验：curated data 相比 raw web 提高四任务均值 3.51 分。5B-token 比较中，部分参数训练恢复 full CPT 的 94% 增益、耗时为 52%；均值 73.19 vs 73.58。恢复比例是相对 base 的局部增益，不是保留 94% 全部能力。[6]

VANE：在固定语义空间预测下一帧

Learning from Next-Frame Prediction: Towards Unified and Scalable Visual Representation Learning ↗
Yifeng Yao et al.
10月22日 00:46 EDT · v1

冻结 semantic tokenizer，causal encoder 预测下一整帧 embedding，辅助 decoder 保留局部细节；报告模型与数据 scaling。EPIC-KITCHENS-100 anticipation 的 mean-class recall@5 比 V-JEPA 2.1 高 7.1 分；摘要未给严格预算匹配细节。[7]

场景覆盖与闭环导航的数据 scaling

AirPlayground: Benchmarking Aerial Navigation across Diverse Reconstructed Environments ↗
Rangya Zhang et al.
10月21日 09:13 EDT · v1

94 个重建场景、94K demonstrations、46.5M observation-state-action samples。ACT 训练从 5 扩到 70 scenes，seen／unseen median success 分别 30.6%→41.2%、16.8%→29.4%；离线预测误差与闭环成功不能互换。[8]

World of SWECraft: Agent Collaboration at Scale via Simulated Software Worlds ↗
Shannon Zejiang Shen et al. · Luke Zettlemoyer
首发10月16日；v2 10月21日 13:59 EDT

以依赖 Python 包的隐藏下游效率评估多 agent 协作；三类世界、八模型、超过 10,000 agent-hours，最佳报告下游效率提高至多 31%。此处补充 Luke 作者跟踪记录；不能把这些旧有结论认定为 v2 新增发现。[9]

压缩历史之前，先决定保留什么

Mamba: Linear-Time Sequence Modeling with Selective State Spaces ↗
Albert Gu · Tri Dao
首发2023-12-01；COLM 2024；所读 v2 2024-05-31
COLM 2024 Outstanding Paper Award ↗

S4（2022）用固定线性系统压缩历史，线性注意力（2020）用有限状态累加。但语言里的“哪些 token 值得记住”依赖内容；Mamba（2024）让写入、读取与遗忘随输入变化。[10]

单 channel 记号；N 维状态、固定对角 A；完整层并行作用于 D 个 channels
ht=Aˉtht−1+Bˉtxt,yt=Ctht,Bt=sB(xt), Ct=sC(xt), Δt=softplus⁡(b+sΔ(xt))h_t=\bar A_t h_{t-1}+\bar B_t x_t,\quad y_t=C_t h_t,\qquad B_t=s_B(x_t),\ C_t=s_C(x_t),\ \Delta_t=\operatorname{softplus}(b+s_\Delta(x_t))ht​=Aˉt​ht−1​+Bˉt​xt​,yt​=Ct​ht​,Bt​=sB​(xt​), Ct​=sC​(xt​), Δt​=softplus(b+sΔ​(xt​))
原文 ZOH 离散化；非可逆处可用连续延拓理解
Aˉt=eΔtA,Bˉt=(ΔtA)−1(eΔtA−I)ΔtBt\bar A_t=e^{\Delta_t A},\qquad\bar B_t=(\Delta_t A)^{-1}(e^{\Delta_t A}-I)\Delta_t B_tAˉt​=eΔt​A,Bˉt​=(Δt​A)−1(eΔt​A−I)Δt​Bt​
原文定理 1 的标量特例：exp(−softplus(z))=1−sigmoid(z)
N=1,A=−1,B=1,Δt=log⁡(1+ezt)⟹ht=(1−gt)ht−1+gtxt,gt=σ(zt)N=1,\quad A=-1,\quad B=1,\quad\Delta_t=\log(1+e^{z_t})\quad\Longrightarrow\quad h_t=(1-g_t)h_{t-1}+g_tx_t,\quad g_t=\sigma(z_t)N=1,A=−1,B=1,Δt​=log(1+ezt​)⟹ht​=(1−gt​)ht−1​+gt​xt​,gt​=σ(zt​)

小 gate 保留状态并忽略当前输入，大 gate 重置到当前输入；该标量解释不是完整多 channel 网络的收敛定理。输入相关系数打破固定卷积，却保留仿射复合的结合律。[10]

解释 scan 的等价代数表示；由仿射复合可直接验证结合律
Ft(h)=at⊙h+bt,(a2,b2)∘(a1,b1)=(a2⊙a1, a2⊙b1+b2)F_t(h)=a_t\odot h+b_t,\qquad (a_2,b_2)\circ(a_1,b_1)=(a_2\odot a_1,\ a_2\odot b_1+b_2)Ft​(h)=at​⊙h+bt​,(a2​,b2​)∘(a1​,b1​)=(a2​⊙a1​, a2​⊙b1​+b2​)

于是可并行 prefix scan。原文再把离散化和递推融合到 SRAM，并在反向重算状态，避免向 HBM 写出完整 B×L×D×N 状态张量；选择机制与硬件实现共同支撑线性序列复杂度。[10]

证据边界

已读 §2、§3.1–3.5、定理1及 §4.1 的 selective-copy／induction 设定。有限维状态仍是信息瓶颈；线性复杂度不保证所有检索任务都能替代 attention。讨论：在固定 state dimension 下，能否刻画内容选择带来的可保留信息上限？[10][11]
